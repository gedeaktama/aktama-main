## 🚀 FITUR CMS (WORDPRESS-GRADE NO-CODE)
1. **Postingan Berita / Artikel (WordPress Post Experience)**:
   - Rich-Text WYSIWYG Editor (TinyMCE 6) dengan format lengkap & tab Visual / HTML.
   - Tombol **"Tambah Media"**: Upload gambar langsung ke konten di posisi kursor.
   - **Yoast / Rank Math SEO Simulator**: Pratinjau Google Search SERP real-time & indikator karakter.
   - Kategori interaktif (tambah kategori baru instan via AJAX tanpa reload halaman).
   - Gambar Unggulan (Thumbnail 16:9), Tag kata kunci, status terbit, dan tanggal publikasi.
2. **Tambah Halaman Baru (WordPress Page Experience)**:
   - **Dual Engine**: Pilihan **Editor Standar (WYSIWYG)** atau **Visual Drag & Drop Canvas (GrapesJS)**.
   - **Page Attributes**: Pilihan template (*Default*, *Full Width*, *Blank Canvas*), urutan menu, dan gambar unggulan.
3. **Modular Section Builder Beranda**: Drag & Drop urutan seksi beranda, sembunyikan/tampilkan seksi.
4. **Pengaturan Menu Navigasi**: Drag & Drop tata letak navigasi header & footer.
5. **Pengaturan Branding**: Upload Logo, Cap Resmi, Favicon, serta info Topbar & Footer.
