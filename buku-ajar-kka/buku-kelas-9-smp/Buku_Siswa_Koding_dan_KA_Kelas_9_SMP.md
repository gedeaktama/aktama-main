### Keterbatasan Koding Blok vs Keunggulan Bahasa Tekstual
Meskipun koding blok sangat ramah bagi pemula, lingkungan blok memiliki beberapa keterbatasan mendasar ketika kita ingin memecahkan masalah komputasi dunia nyata:

## C. LINGKUNGAN KERJA PYTHON & PERINTAH CETAK PERTAMA: print()

### Perintah Paling Legendaris: print()
Perintah dasar pertama yang wajib dikuasai adalah fungsi `print()`. Fungsi ini bertugas menampilkan keluaran (*output*) berupa teks, angka, atau hasil perhitungan ke layar konsol monitor pengguna.

Perhatikan aturan penulisan `print()` berikut:
```python
# Mencetak teks string (wajib diapit tanda petik satu ' atau petik dua ")
print("Selamat datang di Laboratorium Sains Komputasi SMP!")

# Mencetak angka matematika (tidak boleh menggunakan tanda petik)
print(2025)

# Mencetak hasil operasi hitung otomatis
print(15 + 25 * 2)   # Hasil yang keluar di layar adalah 65
```

> **Wawasan Koder: Jangan Lupakan Baris Komentar (#)**  
> Tanda pagar (`#`) digunakan untuk menuliskan **Komentar (*Comments*)**. Komputer akan secara otomatis mengabaikan teks apa pun yang berada di belakang tanda `#`. Komentar ditulis murni untuk membantu diri kita sendiri atau rekan satu tim mengingat fungsi dari blok kode tersebut. Menulis komentar yang jelas adalah tanda koder yang bertanggung jawab!

## D. VARIABEL, TIPE DATA, & INPUT INTERAKTIF

Program komputer tidak akan berguna jika hanya menampilkan teks statis. Sebuah program harus mampu menyimpan data di memori dan berinteraksi secara dinamis dengan penggunanya.

### 1. Mengenal Variabel dan Tiga Tipe Data Utama
Variabel adalah sebuah "kotak penyimpanan berlabel" di dalam memori komputer yang dapat menyimpan sebuah nilai. Nilai di dalam kotak tersebut dapat diubah-ubah (*variable*) sepanjang program berjalan.

Di dalam Python, terdapat tiga tipe data dasar yang paling sering digunakan:
* **String (`str`):** Tipe data teks atau kumpulan karakter alfabet/simbol yang selalu diapit tanda petik. Contoh: `"Rian Pratama"`, `"SMP Nusantara"`, `"A"`.
* **Integer (`int`):** Tipe data bilangan bulat (positif, negatif, atau nol) tanpa pecahan. Contoh: `14`, `-5`, `100`.
* **Float (`float`):** Tipe data bilangan desimal atau pecahan yang ditandai dengan tanda titik (*bukan koma!*). Contoh: `3.14`, `72.5`, `0.08`.

```python
# Membuat variabel dan menetapkan nilainya
nama_siswa = "Ayu Sekar"    # Tipe data String
usia = 14                   # Tipe data Integer
tinggi_badan = 158.5        # Tipe data Float
```

### 2. Menerima Input Dinamis dari Pengguna: input()
Untuk membuat program interaktif yang meminta data dari pengguna melalui papan ketik (*keyboard*), kita menggunakan fungsi `input()`.

Perhatikan hal sangat krusial ini: **Fungsi `input()` di Python secara baku (default) SELALU menghasilkan data bertipe String (teks)!**
Jika kalian meminta pengguna memasukkan angka untuk dijumlahkan:
```python
# PERINGATAN: Cara yang salah!
angka1 = input("Ketik angka pertama: ")   # Pengguna mengetik 5 (disimpan sebagai teks "5")
angka2 = input("Ketik angka kedua: ")     # Pengguna mengetik 3 (disimpan sebagai teks "3")
print(angka1 + angka2)                   # Hasilnya BUKAN 8, melainkan teks "53"!
```

Agar komputer memperlakukan masukan tersebut sebagai angka matematika murni, kita wajib melakukan **Konversi Tipe Data (*Type Casting*)** menggunakan fungsi `int()` atau `float()`:
```python
# CARA YANG BENAR DENGAN TYPE CASTING:
angka1 = int(input("Ketik angka pertama: "))   # Dikonversi menjadi integer 5
angka2 = int(input("Ketik angka kedua: "))     # Dikonversi menjadi integer 3
print("Hasil penjumlahan:", angka1 + angka2)  # Menghasilkan angka 8 yang benar!
```

## E. STRUKTUR KEPUTUSAN MULTI-KONDISI: if - elif - else & ATURAN INDENTASI

Dalam kehidupan sehari-hari, kita sering membuat keputusan bertingkat. Jika nilai rapor kita di atas 85, kita mendapat predikat A; jika nilai antara 70-84 mendapat B; jika nilai antara 60-69 mendapat C; dan jika di bawah 60 kita harus mengikuti remedial.

Dalam bahasa Python, keputusan multi-kondisi ini disusun menggunakan struktur: `if - elif - else`. Kata `elif` merupakan singkatan elegan dari *else-if*.

[[IMAGE: bab1_struktur_kondisi_if_elif_else.png | Gambar 1.4: Struktur Keputusan Multi-Kondisi: Diagram Alur dan Kode if - elif - else]]

### Aturan Emas Indentasi Python (The 4-Space Rule)
Berbeda dengan bahasa pemrograman lain yang menggunakan tanda kurung kurawal `{ }` untuk menandai blok percabangan, Python menggunakan **Indentasi** (ruang kosong menjorok ke dalam, standarnya adalah **4 spasi** atau satu kali tombol *Tab*).

Setiap kali kalian menuliskan tanda titik dua (`:`) di akhir baris `if`, `elif`, atau `else`, baris di bawahnya **WAJIB MENJOROK** ke dalam! Jika spasinya tidak lurus atau lupa menjorok, Python akan langsung memprotes dengan pesan galat: `IndentationError`!

```python
# Program Penentu Kategori Nilai Ujian
```

## F. PERULANGAN OTOMATIS BERHITUNG: for DAN range()

Bayangkan jika guru meminta kalian menuliskan teks *"Saya berjanji akan belajar koding dengan tekun"* sebanyak 100 kali. Jika diketik manual baris demi baris, jari kalian pasti akan kram dan lelah!

Di dalam Python, kita dapat memanfaatkan perulangan `for` yang dipadukan dengan fungsi pencacah deret angka `range()`.

### Memahami Fungsi range()
Fungsi `range(awal, akhir, langkah)` menghasilkan urutan deretan angka.
* `range(5)` -> Menghasilkan angka: 0, 1, 2, 3, 4 (Perhatikan: angka batas akhir 5 tidak diikutsertakan!).
* `range(1, 6)` -> Menghasilkan angka: 1, 2, 3, 4, 5.
* `range(2, 11, 2)` -> Menghasilkan deret bilangan genap: 2, 4, 6, 8, 10 (melompat 2 langkah).

Contoh mencetak tabel perkalian 7 secara otomatis hanya dalam 3 baris kode:
```python
print("--- TABEL PERKALIAN 7 OTOMATIS ---")
for i in range(1, 11):
    hasil = i * 7
    print(f"7 x {i} = {hasil}")
```

Hanya dalam sekejap mata, komputer akan menghitung dan mencetak sepuluh baris perkalian dengan rapi tanpa ada satu pun angka yang keliru!

## D. OLAH DATA KUANTITATIF DENGAN RUMUS SPREADSHEET

Setelah survei ditutup dan terkumpul 150 tanggapan, data mentah otomatis tersimpan di dalam lembar kerja digital (*Spreadsheet*). Untuk membedah pola data ini, kita tidak perlu menghitung manual menggunakan kalkulator genggam satu per satu!

### Lima Rumus Sakti Spreadsheet untuk Analisis Data:
1. **=AVERAGE(Rentang_Sel):** Menghitung nilai rata-rata dari sekelompok angka.  
   * Contoh: `=AVERAGE(D2:D151)` -> Menghitung rata-rata jam tidur malam seluruh siswa.
2. **=COUNTIF(Rentang_Sel; "Kriteria"):** Menghitung berapa banyak baris yang memenuhi syarat tertentu.  
   * Contoh: `=COUNTIF(E2:E151; "Tidak Sarapan")` -> Menghitung berapa orang siswa yang sama sekali tidak sarapan pagi.
3. **=SUM(Rentang_Sel):** Menjumlahkan seluruh total angka pada sebuah kolom.  
   * Contoh: `=SUM(F2:F151)` -> Menghitung total porsi air putih yang diminum seluruh responden.
4. **=MAX(Rentang_Sel) & =MIN(Rentang_Sel):** Menemukan nilai tertinggi dan nilai terendah dalam dataset.
5. **Penyaringan Cerdas (*Filter Data*):** Fitur untuk menampilkan hanya kelompok tertentu, misalnya: menyaring siswa yang memiliki skor fokus < 3 untuk melihat menu sarapan apa yang paling banyak mereka konsumsi.

## E. SENI NARASI VISUAL (DATA STORYTELLING): MEMILIH GRAFIK YANG TEPAT

Pernahkah kalian melihat seseorang mempresentasikan data survei dengan menampilkan tabel berisi 500 angka kecil-kecil di layar proyektor? Seluruh audiens di ruangan pasti akan menguap bosan dan tidak memahami intisari pesan yang disampaikan!

Inilah mengapa seorang ilmuwan komputasi wajib menguasai seni **Data Storytelling**: menyajikan data angka dalam bentuk grafik visual yang memikat dan mudah dipahami dalam sekali pandang.

[[IMAGE: bab2_panduan_pemilihan_grafik_data.png | Gambar 2.3: Panduan Pemilihan Grafik: Memilih Visual yang Tepat untuk Audiens]]

### Tiga Jenis Grafik Utama dan Panduan Penggunaannya:
1. **Diagram Batang (*Bar / Column Chart*):**  
   * *Fungsi Terbaik:* Membandingkan jumlah kuantitas antar kategori yang berbeda.  
   * *Contoh Tepat:* Membandingkan jumlah siswa yang sarapan roti, nasi uduk, bubur, atau tidak sarapan sama sekali.
2. **Diagram Garis (*Line Chart*):**  
   * *Fungsi Terbaik:* Menampilkan tren fluktuasi perubahan nilai dari waktu ke waktu (*continuous time-series*).  
   * *Contoh Tepat:* Memperlihatkan grafik penurunan tingkat rasa kantuk siswa dari jam pelajaran ke-1 (pukul 07.30) hingga jam ke-6 (pukul 13.00).
3. **Diagram Lingkaran (*Pie Chart*):**  
   * *Fungsi Terbaik:* Menampilkan proporsi bagian dari sebuah total kesatuan utuh (100%).  
   * *Peringatan Desain:* Hanya gunakan jika kategori tidak lebih dari 5 potong! Jika potongannya ada 15 buah, diagram lingkaran akan tampak seperti roda yang semrawut dan sulit dibedakan warnanya.

## F. ETIKA PRIVASI DATA: DE-IDENTIFIKASI & ANONIMITAS RESPONDEN

Dalam era digital saat ini, data pribadi warga negara dilindungi secara ketat oleh hukum negara melalui **Undang-Undang Perlindungan Data Pribadi (UU No. 27 Tahun 2022 / UU PDP)**.

[[IMAGE: bab2_infografis_deidentifikasi_data.png | Gambar 2.4: Etika Privasi Riset: De-identifikasi dan Anonimitas Responden Survei]]

### Kewajiban Moral Peneliti: De-identifikasi Data
Ketika kalian membagikan kuesioner survei di lingkungan sekolah atau masyarakat, responden bersedia menjawab jujur karena percaya bahwa identitas mereka tidak akan disalahgunakan atau dipermalukan di depan umum.

Sebelum lembar data survei dipublikasikan atau ditunjukkan ke pihak lain, kalian **WAJIB** melakukan proses **De-identifikasi Data**:
1. **Hapus Kolom Identitas Langsung:** Hapus permanen kolom nama lengkap, nomor induk siswa (NIS), alamat rumah, dan nomor telepon seluler.
2. **Gunakan Kode Anonim (*Pseudonymization*):** Ganti nama responden dengan nomor urut acak, misalnya: `Responden_#001`, `Responden_#002`.
3. **Sajikan Data Agregat:** Jangan mempublikasikan catatan perorangan; sajikan kesimpulan dalam bentuk persentase kelompok (misal: *"82% siswa kelas IX sarapan dengan menu seimbang"*).

## B. PAYUNG HUKUM RUANG SIBER INDONESIA: MEMAHAMI UU ITE DAN UU PDP

Banyak orang mengira bahwa dunia maya adalah ruang bebas tanpa aturan di mana siapa pun bisa bertindak sesuka hatinya tanpa konsekuensi. Anggapan ini keliru dan sangat berbahaya! Negara Kesatuan Republik Indonesia memiliki perangkat hukum yang kuat dan tegas untuk menegakkan keadilan di ranah digital.

[[IMAGE: bab3_timbangan_keadilan_hukum_siber.png | Gambar 3.2: Payung Hukum Ruang Siber Indonesia: Memahami UU ITE dan UU Perlindungan Data Pribadi (UU PDP)]]

### 1. Undang-Undang Informasi dan Transaksi Elektronik (UU ITE)
Undang-Undang ITE (UU No. 11 Tahun 2008 yang telah disempurnakan melalui UU No. 1 Tahun 2024) adalah payung hukum utama yang mengatur lalu lintas informasi digital di Indonesia:
* **Larangan Penyebaran Hoaks yang Menyesatkan (Pasal 28):** Siapa pun yang sengaja menyebarkan berita bohong yang memicu keonaran di masyarakat atau merugikan konsumen dapat dipidana penjara hingga 6 tahun dan denda miliaran rupiah.
* **Larangan Pencemaran Nama Baik & Ujaran Kebencian (Pasal 27 & 28):** Melarang penghinaan, fitnah siber, serta ujaran kebencian berbasis Suku, Agama, Ras, dan Antargolongan (SARA) di media sosial.
* **Larangan Akses Ilegal (*Hacking* & Penyadapan) (Pasal 30 & 31):** Meretas akun orang lain, menyadap pesan obrolan, atau menerobos sistem komputer instansi tanpa hak adalah kejahatan kriminal berat.

### 2. Undang-Undang Perlindungan Data Pribadi (UU PDP No. 27 Tahun 2022)
Undang-undang bersejarah ini menjamin kedaulatan warga negara atas data pribadinya:
* **Kategori Data Spesifik yang Dilindungi:** Data kesehatan rekam medis, data biometrik (sidik jari dan pindai retina), data genetika, orientasi seksual, dan catatan kejahatan.
* **Kewajiban Pengendali Data (Sekolah/Perusahaan):** Wajib meminta persetujuan tertulis (*consent*), menjamin keamanan enkripsi, dan segera memberitahukan pemilik data jika terjadi kebocoran server dalam waktu maksimal 3 x 24 jam.
* **Hak Subjek Data:** Setiap orang berhak menolak data pribadinya digunakan untuk iklan komersial dan berhak meminta data pribadinya dihapus permanen (*Right to Erasure*).

## C. DILEMA HAK CIPTA KARYA AI & KEJUJURAN AKADEMIS

Salah satu debat hukum paling sengit di dunia saat ini adalah: **Apakah karya yang dihasilkan oleh kecerdasan artifisial dapat dilindungi oleh Undang-Undang Hak Cipta?**

### Pandangan Hukum Internasional & Nasional:
Menurut undang-undang hak cipta di Indonesia (UU No. 28 Tahun 2014) maupun standar hukum internasional (seperti putusan *US Copyright Office*):
1. **Pencipta Haruslah Manusia (*Human Authorship*):** Hak cipta hanya dapat diberikan kepada manusia sejati yang mencurahkan tenaga kreatif, imajinasi, dan keahlian aslinya. Mesin komputer, algoritma kecerdasan artifisial, atau hewan tidak diakui sebagai subjek hukum pencipta.
2. **Karya Murni Hasil Prompting AI Tidak Memiliki Hak Cipta:** Jika sebuah gambar atau esai dihasilkan 100% murni oleh AI hanya berdasarkan perintah teks pengguna, karya tersebut dianggap sebagai milik publik (*public domain*) yang tidak dapat diklaim hak ciptanya secara eksklusif oleh pembuat prompt.
3. **Karya Kolaborasi Manusia-AI:** Hak cipta baru dapat diberikan jika manusia melakukan modifikasi kreatif yang substansial (misalnya manusia menggambar sketsa awal, mengatur komposisi warna manual, dan AI hanya membantu merapikan bayangan).

### Etika Kejujuran Akademis di Sekolah
Bagi peserta didik kelas IX, ketersediaan AI generatif bukanlah jalan pintas untuk berbuat curang! Menyalin-tempel (*copy-paste*) tugas esai atau laporan praktikum yang ditulis oleh AI lalu mengklaimnya sebagai karya tulisan sendiri adalah bentuk **Plagiarisme Digital** yang mencoreng integritas akademik.

Gunakan AI sebagai **Mitra Diskusi Kritis (*Thinking Partner*)**: Mintalah AI menguji argumen kalian, memberikan sudut pandang alternatif, atau menyarankan bahan bacaan ilmiah, namun seluruh analisis kesimpulan akhir dan tulisan wajib lahir dari olah pikir nurani kalian sendiri!

## D. SEGITIGA TANGGUNG JAWAB MORAL AI

Bayangkan skenario dilema nyata berikut: Sebuah mobil ambulans otonom yang dikendalikan sistem AI melaju membawa pasien kritis. Tiba-tiba di perempatan jalan, seorang penyeberang jalan menerobos lampu merah. Sistem AI ambulans melakukan pengereman mendadak namun tetap menabrak penyeberang jalan tersebut hingga terluka.

### Membedah Tiga Sisi Tanggung Jawab:
Sistem komputer atau robot cerdas tidak memiliki kesadaran, kehendak bebas, atau harta benda; sehingga AI tidak dapat diseret ke dalam penjara atau dijatuhi denda pengadilan. Tanggung jawab hukum selalu bermuara pada tiga pihak manusia di belakangnya:

1. **Pengembang Perangkat Lunak (*Software Developers / Vendors*):**  
   Bertanggung jawab jika terbukti ada kelalaian fatal dalam penulisan algoritma, kegagalan uji keamanan sistem, atau pengabaian standar keselamatan industri.
2. **Penyedia Dataset Latih (*Data Providers*):**  
   Bertanggung jawab jika model AI mengalami bias atau kebutaan sensorik akibat data latih yang dipasok tidak representatif, mengandung diskriminasi tersembunyi, atau mengabaikan kondisi keselamatan cuaca buruk.
3. **Operator / Pengawas Manusia (*Human Oversight / Users*):**  
   Bertanggung jawab jika pengemudi atau dokter sengaja mematikan fitur peringatan darurat, lalai mengawasi jalannya sistem otomatis, atau menggunakan teknologi di luar prosedur standar operasional (SOP).

Prinsip dasar etika global UNESCO: *"Teknologi otonom tidak boleh melepaskan manusia dari rantai pertanggungjawaban moral dan hukum."*

## E. TRANSFORMASI DUNIA KERJA: MEMETAKAN KETERAMPILAN MASA DEPAN

### Lima Tahapan Metodologi Design Thinking:
1. **Tahap 1: Empathize (Mendengar & Merasakan):**  
   Terjun langsung ke lapangan untuk mengamati, mewawancarai, dan mendengarkan keluh kesah calon pengguna (*users*). Apa kesulitan terbesar yang mereka alami setiap hari? Apa harapan mereka yang belum terwujud?

3. **Tahap 3: Ideate (Curah Pendapat Liar Tanpa Batas):**  
   Duduk bersama tim untuk mengumpulkan puluhan ide solusi alternatif. Pada tahap ini, dilarang mengkritik ide rekan kelompok! Biarkan kreativitas mengalir sebebas-bebasnya sebelum memilih satu ide solusi yang paling berdampak dan realistis.
4. **Tahap 4: Prototype (Membangun Model Versi Awal):**  
   Mewujudkan ide abstrak menjadi benda nyata: membangun skrip program Python fungsional, mendesain formulir digital, atau merancang infografis media pendukung. Prototipe tidak harus sempurna, yang terpenting alur kerjanya dapat didemonstrasikan.
5. **Tahap 5: Test (Uji Coba Pengguna Nyata & Evaluasi):**  
   Memberikan prototipe kepada calon pengguna asli untuk dicoba langsung. Amati bagian mana yang membingungkan mereka, catat kritik dan saran mereka, lalu perbaiki kode program sebelum pameran akbar!

### Rancangan Kode Prototipe (Contoh Tema Bank Sampah):
```python
# ==============================================================
# PROYEK CAPSTONE FASE D KELAS IX SMP NUSANTARA
# SISTEM BANK SAMPAH DIGITAL SEKOLAH (VERSI PROTOTIPE 2.0)
# ==============================================================

print("==================================================")
print("   SISTEM BANK SAMPAH DIGITAL SMP NUSANTARA       ")
print("   Peduli Lingkungan • Bersih Sekolahku • Hijau Bumiku")
print("==================================================")

data_kelas = {
    "VII-A": 0, "VII-B": 0,
    "VIII-A": 0, "VIII-B": 0,
    "IX-A": 0, "IX-B": 0
}

# Tarif Poin per Kilogram Sampah Terpilah
POIN_PLASTIK = 5000   # Rp5.000 / kg botol plastik bersih
POIN_KERTAS = 3000    # Rp3.000 / kg kardus & kertas bekas

lanjutkan = True

while lanjutkan:
    print("
--- MENU OPERASIONAL BANK SAMPAH ---")
    print("1. Setor Sampah Daur Ulang")
    print("2. Lihat Saldo Tabungan Lingkungan Seluruh Kelas")
    print("3. Selesai & Keluar Program")
    
    pilihan = input("Pilih menu (1/2/3): ")
    
    if pilihan == "1":
        kls = input("Masukkan Nama Kelas (misal: IX-A): ")
        if kls in data_kelas:
            print("Jenis Sampah: 1. Botol Plastik | 2. Kertas/Kardus")
            jenis = input("Pilih jenis (1/2): ")
            berat = float(input("Berat timbangan sampah (kg): "))
            
            if jenis == "1":
                pendapatan = berat * POIN_PLASTIK
            elif jenis == "2":
                pendapatan = berat * POIN_KERTAS
            else:
                print("Jenis sampah tidak valid!")
                pendapatan = 0
                
            data_kelas[kls] += pendapatan
            print(f"Sukses! Tabungan kelas {kls} bertambah Rp{pendapatan:,.0f}")
        else:
            print("Kelas tidak ditemukan dalam database!")
            
    elif pilihan == "2":
        print("
=== KLASEMEN TABUNGAN HIJAU KELAS ===")
        total_sekolah = 0
        for k, v in data_kelas.items():
            print(f"Kelas {k:7} : Rp{v:,.0f}")
            total_sekolah += v
        print("-------------------------------------")
        print(f"Total Tabungan Lingkungan: Rp{total_sekolah:,.0f}")
        
    elif pilihan == "3":
        print("Terima kasih atas kontribusi nyata merawat bumi kita!")
        lanjutkan = False
    else:
        print("Pilihan menu tidak valid. Silakan coba lagi.")
```

## GLOSARIUM ISTILAH SAINS KOMPUTASI & AI LENGKAP FASE D

* **Aggregated Data (Data Agregat):** Data ringkasan statistik yang diperoleh dari penggabungan banyak data individu sehingga tidak lagi menampilkan informasi sensitif perorangan.
* **Capstone Project:** Proyek penugasan mandiri atau kelompok berskala besar di akhir jenjang pendidikan yang mengintegrasikan seluruh kompetensi belajar yang telah dipelajari selama tiga tahun.
* **Data Storytelling:** Seni mengomunikasikan wawasan dan kesimpulan yang diperoleh dari analisis data menggunakan narasi yang menarik, konteks yang relevan, dan visualisasi grafik yang tepat.
* **De-identifikasi Data:** Proses penghapusan atau penyamaran data pribadi (seperti nama, nomor kontak, dan alamat) dari sebuah dataset agar identitas responden tidak dapat dilacak kembali.
* **Design Thinking:** Metodologi perancangan pemecahan masalah yang berpusat pada manusia (*human-centered*), terdiri atas lima tahapan: *Empathize, Define, Ideate, Prototype,* dan *Test*.
* **Elif (Else-If):** Kata kunci dalam bahasa Python yang digunakan untuk menguji kondisi alternatif kedua atau ketiga jika kondisi `if` sebelumnya tidak terpenuhi.
* **Exhibition Day:** Hari pameran dan unjuk gelar karya di mana para siswa mempresentasikan produk inovasi digital hasil kerja kelompoknya di hadapan guru, orang tua, dan komunitas.
* **Float:** Tipe data komputer yang digunakan untuk menampung bilangan pecahan atau angka yang memiliki tanda desimal koma (misalnya 3.14 atau 72.5).
* **Indentasi:** Ruang spasi kosong di awal baris kode (standar Python adalah 4 spasi) yang berfungsi mengelompokkan blok instruksi di dalam fungsi, percabangan, atau perulangan.
* **Integer:** Tipe data komputer yang digunakan untuk merepresentasikan bilangan bulat positif, negatif, atau nol tanpa pecahan (misalnya -5, 0, 100).
* **Moot Court (Peradilan Semu):** Aktivitas pembelajaran berbasis simulasi persidangan hukum di mana siswa bermain peran sebagai hakim, jaksa penuntut, pembela, dan saksi ahli.
* **Prototype (Prototipe):** Model kerja awal atau versi percontohan sederhana dari sebuah aplikasi/produk yang dibuat untuk menguji kelayakan ide sebelum diproduksi secara massal.
* **Syntax Error (Galat Sintaks):** Kesalahan dalam penulisan aturan tanda baca atau kata kunci bahasa pemrograman yang menyebabkan kode program gagal dieksekusi oleh mesin penerjemah.
* **Undang-Undang PDP:** Undang-Undang Perlindungan Data Pribadi (UU No. 27 Tahun 2022) yang mengatur hak asasi setiap warga negara Indonesia atas keamanan dan kerahasiaan data pribadinya di ranah digital.
* **User Testing:** Tahapan pengujian produk prototipe langsung kepada calon pengguna nyata untuk mendapatkan respon balik (*feedback*) jujur demi penyempurnaan produk.

### PROFIL PENULIS & FASILITATOR ToT NASIONAL

[[IMAGE: foto_penulis.jpg | Foto Penulis: Gede Erik Aktama, S.Pd., M.Pd.]]

**Gede Erik Aktama, S.Pd., M.Pd.**  
*Fasilitator Nasional Bimbingan Teknis & Training of Trainers (ToT) Koding dan Kecerdasan Artifisial Kemendikdasmen RI*  
*Dosen Lektor & Ketua Program Studi S1 Sistem Komputer, Fakultas Teknik dan Informatika, Universitas Parna Raya (UNIPAR) Manado*

Penulis adalah akademisi, peneliti sains data, dan praktisi pendidikan komputasi yang berdomisili di Kota Manado, Sulawesi Utara. Menyelesaikan pendidikan Sarjana Pendidikan (S.Pd.) pada Program Studi Pendidikan Teknik Informatika serta gelar Magister Pendidikan (M.Pd.) pada Program Studi Pendidikan Teknologi dan Kejuruan dari Universitas Pendidikan Ganesha (UNDIKSHA), Singaraja. Saat ini, penulis aktif mengemban jabatan fungsional akademik **Lektor** (SK Mendiktisaintek RI No. 0044/LL16/KP.07/2025) serta dipercaya menjabat sebagai Ketua Program Studi S1 Sistem Komputer di Universitas Parna Raya Manado.

Sebagai akademisi yang mendedikasikan ilmunya pada transformasi pendidikan dasar dan menengah nasional, penulis dipercaya oleh Direktorat Jenderal Guru dan Tenaga Kependidikan, Kementerian Pendidikan Dasar dan Menengah RI sebagai **Fasilitator Nasional** dalam Bimbingan Teknis dan *Training of Trainers* (ToT) Pembelajaran Koding dan Kecerdasan Artifisial (KKA) untuk jenjang SD, SMP, SMA, dan SMK.

Penulis memiliki kepakaran riset dalam bidang *Computational Thinking & Textual Programming in K-12*, *Artificial Intelligence Ethics & Machine Perception*, *Educational Data Science*, serta Perancangan Kurikulum Inovasi berbasis *Deep Learning*. Karya buku teks Fase D Kelas IX ini dipersembahkan dengan segenap cinta bagi seluruh putra-putri SMP/MTs di Indonesia agar siap menyongsong masa depan dengan keunggulan nalar budi pekerti luhur!
