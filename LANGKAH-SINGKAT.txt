--- TAHAP 2: DEPLOY PERTAMA KALI KE SERVER HOSTING VIA SSH ---
--------------------------------------------------------------------------------

1. Buka terminal (CMD / PowerShell / Git Bash) di komputer Anda, lalu login SSH:
   ssh -p 65002 u107454400@147.93.80.47

2. Masuk ke direktori public_html:
   cd /home/u107454400/domains/aktama.com/public_html

3. Kloning source code dari GitHub ke folder 'aktama-main-source':
   git clone https://github.com/gedeaktama/aktama-main.git aktama-main-source

4. Masuk ke folder source code:
   cd aktama-main-source

5. Salin dan sesuaikan file .env:
   cp .env.production.example .env
   (Jika nama database berbeda, edit dengan: nano .env)

6. Jalankan skrip otomatis deployment Niagahoster:
   bash scripts/linux/deploy-niagahoster.sh

7. Selesai! Web utama langsung aktif di:
