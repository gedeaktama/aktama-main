## 3. PENJELASAN MASALAH TEKNIS & SOLUSI YANG DITERAPKAN

### A. Masalah Ikon Tidak Muncul (Icon Kosong / Tidak Tahu Edit atau Hapus)
- **Penyebab Utama**: 
  1. File SCSS terkompilasi Vite sebelumnya mengimpor font Bootstrap Icons dengan format URL absolut `/build/assets/...`. Di server web Apache XAMPP, path ini mengarah ke `http://localhost:8080/build/...` (root Apache) sehingga font 404 (gagal termuat).
  2. Saat koneksi internet lambat atau CDN terhalang, browser tidak memiliki cadangan font lokal yang valid.
  3. Tombol aksi di tabel data sebelumnya hanya menggunakan tag `<i class="bi bi-trash"></i>` tanpa label teks, sehingga jika ikon gagal me-render seketika, tombol tampak seperti kotak kosong tanpa kejelasan fungsi.
- **Solusi yang Diterapkan**:
  1. Telah disalin seluruh bundel font Bootstrap Icons ke direktori lokal proyek di `public/vendor/bootstrap-icons/`.
  2. File `layouts/app.blade.php` dan `layouts/admin.blade.php` kini memuat CSS lokal dengan path relatif `{{ asset('vendor/bootstrap-icons/bootstrap-icons.min.css') }}` dan dilengkapi CDN fallback.
  3. Import SCSS yang memicu path absolut telah dihapus dan di-recompile dengan bersih via `npm run build`.
  4. **Semua tombol aksi tabel sekarang memiliki teks label eksplisit berwarna tegas**:
     - Tombol **Edit** berwarna biru outline (`btn-outline-primary`) dengan teks **"Edit"**.
     - Tombol **Hapus** berwarna merah outline (`btn-outline-danger`) dengan teks **"Hapus"**.
     - Tombol **Lihat** berwarna abu-abu (`btn-light border`) dengan teks **"Lihat"**.
     - Tombol handle geser pada menu drag & drop diberi label **"Geser"**.
     - Tombol **Visual Builder** berwarna biru dengan teks **"Visual Builder"**.

### B. Masalah Tautan Menu Navigasi Berujung 404 (Tidak Jadi / Pecah)
- **Penyebab Utama**:
  Item menu dinamis yang tersimpan dalam database menggunakan path seperti `/jasa-website`. Pada HTML murni, tag `<a href="/jasa-website">` akan diarahkan oleh browser ke root origin domain (`http://localhost:8080/jasa-website`), bukan ke subdirektori proyek Laravel (`http://localhost:8080/aktama-main/public/jasa-website`). Hal ini memicu error 404 Apache.
- **Solusi yang Diterapkan**:
  Telah diperbarui logika pembacaan navigasi di `layouts/app.blade.php` (baik pada Header Navbar maupun Footer):
  ```php
  $rawUrl = $nav['url'] ?? '/';
  $targetUrl = str_starts_with($rawUrl, 'http') || str_starts_with($rawUrl, '#') 
      ? $rawUrl 
      : url($rawUrl);
  ```
  Dengan kode ini:
  - Pada lingkungan **Localhost XAMPP**, link otomatis tersambung ke `http://localhost:8080/aktama-main/public/jasa-website`.
  - Pada lingkungan **Shared Hosting / Produksi**, link otomatis menyesuaikan ke domain utama (misal `https://aktama.com/jasa-website`).

## 4. PANDUAN PENGOPERASIAN CMS TANPA EDIT KODE

### 1. Mengubah Logo, Cap Perusahaan, dan Favicon
1. Buka menu **Pengaturan, Logo & Footer** di panel admin.
2. Pada bagian **Logo Resmi Perusahaan**, klik tombol **Pilih File** lalu unggah gambar logo (PNG transparan disarankan).
3. Unggah juga **Cap Resmi Perusahaan** dan **Favicon**.
4. Klik tombol **Simpan Seluruh Pengaturan Situs** di bagian bawah. Logo dan cap akan langsung berubah secara global di seluruh halaman web.

### 2. Mengatur Urutan Seksi Beranda (Opsi A: Modular Builder)
1. Buka menu **Seksi Beranda (Drag & Drop)**.
2. Klik dan tahan tombol **Grip / Geser** pada seksi yang ingin dipindah (misal: naikkan seksi "Pelatihan AI" ke atas "Produk Kopi").
3. Lepaskan kursor pada urutan yang diinginkan. Urutan langsung tersimpan secara otomatis via AJAX.
4. Anda juga dapat menyembunyikan atau menampilkan seksi dengan menekan tombol **Tampil di Web** / **Disembunyikan**.
5. Klik **Edit Teks** untuk mengubah Judul, Subjudul, dan Teks Tombol seksi tersebut tanpa menyentuh kode Blade.

### 3. Membuat Halaman Baru & Desain dengan Visual Canvas (Opsi B)
1. Buka menu **Halaman & Visual Canvas** > Klik **Tambah Halaman Baru**.
2. Masukkan Judul Halaman (slug URL akan otomatis terbuat).
3. Pilih Jenis Editor: **Visual Drag & Drop Canvas**.
4. Simpan, lalu klik tombol **Visual Builder**.
5. Tarik blok-blok siap pakai dari panel samping (Hero Section, 3-Column Features, Pricing Cards, CTA Banner, Video Container).
6. Edit teks dan ganti warna secara langsung di kanvas seperti menggunakan Elementor/GrapesJS.
7. Klik tombol biru **Simpan Desain** di pojok kanan atas. Halaman langsung live!

### 4. Mengatur Menu Header & Footer (Menu Manager)
1. Buka menu **Menu Navigasi (Drag & Drop)**.
2. Pilih tab **Header Utama (Navbar)** atau **Footer Bawah**.
3. Centang halaman yang ingin ditambahkan dari daftar di sebelah kiri lalu klik **Tambahkan ke Menu**, atau ketikkan Tautan Bebas / Custom Link.
4. Geser urutan menu dengan men-drag tombol **Geser**.
5. Hapus item menu yang tidak dibutuhkan dengan menekan tombol merah **Hapus**.
6. Klik **Simpan Susunan Menu**.
